# Chhaya Ahirwar --- Frontend Developer Portfolio

A modern, responsive personal portfolio website built from scratch to
showcase my frontend development skills, projects, services, and contact
information.

## 🚀 Live Demo

**Portfolio:** https://chhyaahirwar84-a11y.github.io/Chhaya-Portfolio/

## 💻 GitHub Repository

**Repository:** https://github.com/chhyaahirwar84-a11y/Chhaya-Portfolio

## ✨ Features

-   Responsive design for desktop, tablet, and mobile devices
-   Modern dark-themed UI
-   Smooth GSAP animations and scroll-based effects
-   Interactive custom cursor on desktop
-   Animated hero section with image movement and parallax effect
-   Responsive mobile navigation menu
-   About, Services, Projects, and Contact sections
-   Interactive service and project cards
-   Full-screen project preview modal
-   Social media and contact links
-   Custom favicon
-   SEO-friendly meta information
-   Open Graph and Twitter Card metadata for social sharing
-   GitHub Pages deployment

## 🛠️ Technologies Used

-   HTML5
-   CSS3
-   JavaScript (ES6+)
-   GSAP
-   ScrollTrigger
-   Remix Icon
-   Google Fonts
-   Git
-   GitHub
-   GitHub Pages

## 🎨 Design & Development

The portfolio was designed and developed from scratch with a focus on:

-   Clean visual hierarchy
-   Responsive layouts
-   Interactive user experience
-   Smooth animations
-   Accessible navigation
-   Project-focused presentation

## 📱 Responsive Design

The website has been tested across different screen sizes to ensure that
the main sections, navigation, project previews, social links, and
footer remain usable on smaller screens.

## ⚙️ Run Locally

Clone the repository:

``` bash
git clone https://github.com/chhyaahirwar84-a11y/Chhaya-Portfolio.git
```

Open the project folder:

``` bash
cd Chhaya-Portfolio
```

Then open `index.html` in a browser or use a VS Code
live-server/live-preview extension.
